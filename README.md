# ปรับ CV ให้ตรงงาน — ตัวต้นแบบ (MVP)

อัปโหลด CV + วางประกาศงาน → AI ให้คะแนนฟรี → จ่ายเงิน → ได้ CV ใหม่เป็น PDF

## เริ่มใช้งาน

ต้องมี [Node.js](https://nodejs.org) เวอร์ชัน 18.18 ขึ้นไป

```bash
npm install
cp .env.example .env.local
npm run dev
```

เปิด http://localhost:3000

ค่าเริ่มต้นเป็น **โหมดทดลอง** (`MOCK_AI=1`) ใช้ข้อมูลตัวอย่าง ไม่ต้องมี API key และไม่เสียค่าใช้จ่าย

## ใช้ AI จริง

1. สมัครและสร้าง API key ที่ https://console.anthropic.com
2. แก้ไฟล์ `.env.local`
   ```
   ANTHROPIC_API_KEY=ใส่คีย์ของคุณ
   MOCK_AI=0
   ```
3. รัน `npm run dev` ใหม่

## ระบบชำระเงิน (Omise PromptPay)

ลำดับการทำงาน: ตรวจฟรี → กดจ่าย → สร้างออร์เดอร์ + QR → ลูกค้าสแกนจ่าย → ระบบตรวจกับ Omise ว่าจ่ายจริง → AI ปรับ CV → เก็บผลไว้ 7 วัน (เปิดลิงก์ `?order=...` กลับมาดูได้)

**ทดสอบบนเครื่อง (ไม่ต้องมีบัญชี Omise):** `PAYMENT_MODE=mock` → หน้า QR จะมีปุ่ม "จำลองว่าจ่ายแล้ว"

**ทดสอบกับ Omise (ยังไม่เก็บเงินจริง):**
1. สมัครที่ https://dashboard.omise.co → เปิดใช้ PromptPay
2. คัดลอก Secret key แบบทดสอบ (`skey_test_...`)
3. ใน `.env.local` ตั้ง `PAYMENT_MODE=omise` และ `OMISE_SECRET_KEY=skey_test_...`
4. ระบบจะสร้าง QR จริงจาก Omise และมีปุ่ม "จำลองว่าจ่ายแล้ว" ให้กดทดสอบ

**เปิดเก็บเงินจริง:**
1. ยืนยันตัวตนกับ Omise จนได้ Secret key จริง (`skey_...` ไม่มีคำว่า test) แล้วใส่แทน
2. ตั้ง Webhook ใน Omise Dashboard ไปที่ `https://โดเมนของคุณ/api/omise/webhook`
   (ไม่ตั้งก็ใช้ได้ หน้าเว็บตรวจสถานะเองทุก 3 วินาที แต่ webhook ช่วยให้ไม่พลาดกรณีลูกค้าปิดหน้าเว็บ)
3. ต้องตั้ง Upstash Redis ด้วย (ดูหัวข้อขึ้นเว็บจริง)

ถ้า AI ปรับ CV ไม่สำเร็จหลังลูกค้าจ่ายเงิน ลูกค้ากด "ลองใหม่" ได้โดยไม่ต้องจ่ายซ้ำ
PromptPay ผ่าน Omise คืนเงินผ่านระบบไม่ได้ ต้องโอนคืนเอง

## จำกัดการใช้งาน

- ตรวจฟรีได้ 5 ครั้งต่อคน (IP) ต่อวัน และรวมทั้งเว็บ 300 ครั้งต่อวัน
- ให้ Claude อ่าน PDF ที่ภาษาไทยเพี้ยนได้ 10 ครั้งต่อคนต่อวัน
- สร้าง QR ได้ 20 ครั้งต่อคนต่อวัน
- ปรับตัวเลขได้ใน `.env.local`
- กันบอทด้วย Cloudflare Turnstile (ฟรี): ใส่ `NEXT_PUBLIC_TURNSTILE_SITE_KEY` และ `TURNSTILE_SECRET_KEY` แล้วจะมีกล่องยืนยันก่อนกดตรวจ

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `app/page.jsx` | หน้าเว็บหลัก (กรอกข้อมูล → ผลคะแนน → QR → CV ใหม่) |
| `app/api/extract/route.js` | อ่านไฟล์ PDF / DOCX / TXT เป็นข้อความ |
| `app/api/analyze/route.js` | ส่วนฟรี: ให้คะแนนและบอกคีย์เวิร์ดที่ขาด (มีจำกัดจำนวนครั้ง) |
| `app/api/order/...` | สร้างออร์เดอร์, QR, ตรวจสถานะ, สร้าง CV หลังจ่ายเงิน |
| `app/api/omise/webhook/route.js` | รับแจ้งเตือนการจ่ายเงินจาก Omise |
| `lib/orders.js` | ขั้นตอนออร์เดอร์ทั้งหมด |
| `lib/omise.js` | เชื่อมต่อ Omise |
| `lib/store.js` | ที่เก็บข้อมูล (Upstash Redis หรือหน่วยความจำ) |
| `lib/ratelimit.js` / `lib/turnstile.js` | จำกัดการใช้งาน / กันบอท |
| `lib/prompts.js` | **Prompt หลัก** ปรับตรงนี้เพื่อเปลี่ยนคุณภาพผลลัพธ์ |
| `lib/claude.js` | เรียก Claude API |
| `lib/mock.js` | ข้อมูลตัวอย่างสำหรับโหมดทดลอง |
| `components/CvTemplate.jsx` + `app/globals.css` | หน้าตา CV และการพิมพ์ PDF |

## ขึ้นเว็บจริง (Vercel)

1. สร้างฐานข้อมูล Redis ฟรีที่ https://upstash.com แล้วคัดลอก REST URL และ REST TOKEN
   (จำเป็น เพราะ Vercel ไม่เก็บข้อมูลในหน่วยความจำข้ามคำขอ ออร์เดอร์และตัวนับจะหาย)
2. อัปโหลดโปรเจกต์ขึ้น GitHub แล้ว Import ที่ https://vercel.com
3. ใส่ค่าทั้งหมดใน Environment Variables ตาม `.env.example`
4. แพ็กเกจฟรีของ Vercel ไม่อนุญาตให้ใช้เชิงพาณิชย์ ถ้าเก็บเงินต้องใช้แพ็กเกจ Pro (ตรวจเงื่อนไขล่าสุดที่ vercel.com)
